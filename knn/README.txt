KNN Shirt Size ML Lab

Double-click "Start KNN.vbs", or run: python ml_knn.py

The lab uses a stratified 80/20 split, training-only standardization,
leakage-free 5-fold CV over k=3,5,7,9, untouched test metrics,
per-class and macro metrics, confusion matrix, ROC-AUC, detailed nearest
neighbours, majority vote, new input prediction, and TXT/CSV reports.

See LAB_GUIDE_BN.txt or the Guide tab for the Bengali explanation and viva notes.
