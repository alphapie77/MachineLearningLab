OVERLEAF UPLOAD INSTRUCTIONS

1. Upload ML_Lab_Report_Overleaf.zip to Overleaf using New Project > Upload Project.
2. Overleaf will use main.tex as the main document.
3. Open report-info.tex and replace Your Name, Student ID, Academic Session,
   University and Instructor Name.
4. In main.tex, fill the performed/submitted dates below each experiment title.
5. Compile with pdfLaTeX.

This is one combined report containing five experiments:
K-Means, KNN, ID3 Decision Tree, Linear SVM and CNN.
Non-linear SVM is intentionally excluded.

The report explains each experiment within its own chapter using intuition,
equations, worked examples, step-by-step procedures, actual figures, output
interpretation, limitations and conclusions.

Optional foundation, viva, glossary, references and submission-checklist blocks
remain in main.tex inside \iffalse ... \fi, so they are excluded from the PDF.
